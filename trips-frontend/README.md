# trips-frontend

The Svelte frontend for the trips API — a static single-page app (SvelteKit +
`adapter-static`). See [docs/frontend.md](../docs/frontend.md) for how it's built, run,
tested and hosted.

```bash
npm ci
npm run dev        # http://localhost:5173 (or `make up` from the repo root)
npm test           # unit + component tests
npm run api:types  # regenerate API types from the running backend
```
